# Snapchat Copy 📸

A Flutter-based Snapchat clone that replicates core Snapchat features with a clean UI and smooth user experience.  
This project works **completely offline** and uses a **local database only** — no backend or cloud services.

## 🎥 Demonstration Video

▶️ Watch the app in action:  
https://drive.google.com/file/d/1swLgLJsp5Iq2wO1tCff2u94iMxpoK7Aw/view?usp=sharing

## 🚀 Features

- Camera capture (photo-based flow)
- Story-style UI and interactions
- Chat-style interface
- Offline data persistence
- Smooth animations and transitions
- Clean and modern UI inspired by Snapchat

---

## 🛠️ Tech Stack

- **Flutter**
- **Dart**
- **Local Database** (offline storage)
- No Firebase
- No Internet dependency

---

## 📱 Offline-First Architecture

This app is designed to work **100% offline**:
- All user data is stored locally
- No API calls or cloud services
- Ideal for demonstrating local storage handling and UI logic

---



## ⚙️ Getting Started

### Prerequisites
- Flutter SDK
- Android Studio / VS Code
- Android Emulator or Physical Device

### Setup Steps

1. Clone the repository:
   git clone https://github.com/dev-abdul-haseeb/Snapchat-clone-.git
2. Navigate to the project directory:
    cd snapchat_copy
3. Get dependencies:
    flutter pub get
4. Run the app:
    flutter run

This project was built to:
